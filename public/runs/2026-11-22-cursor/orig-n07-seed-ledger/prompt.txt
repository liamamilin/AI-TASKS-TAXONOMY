做一个离线种子借还台 index.html，不收集姓名。种类卡显示库存与按种类筛选的事件。嵌入起始库存并提供下列演示动作的单步执行按钮；另有选择种类、借/还、数量表单。借出库存不足、非正整数数量必须被拒绝且不写事件。有效动作写入 localStorage；撤销只撤最后一个有效动作并记录可见说明，重载后状态保持；重置恢复初态。下载 ledger.json（初态、有效事件、当前状态、撤销标记），能从事件复算。页面显著写合成数据、浏览器本地保存。

完整合成输入：
{
  "initial": {
    "豆星": 3,
    "月瓜": 1
  },
  "demo_actions": [
    {
      "type": "borrow",
      "item": "豆星",
      "qty": 2
    },
    {
      "type": "borrow",
      "item": "豆星",
      "qty": 2
    },
    {
      "type": "return",
      "item": "月瓜",
      "qty": 2
    },
    {
      "type": "undo"
    }
  ]
}

必须交付：index.html；ledger.json 演示流程导出；README.md。
客观验收：
1. 动作1后豆星1；动作2被拒绝、库存不变且不计有效事件。
2. 动作3后月瓜3；动作4撤销该归还，最终豆星1/月瓜1，非把全部历史清空。
3. 刷新后最终状态保持；重置恢复3/1；0、-1、1.5和空数量均不入账。
4. 用导出事件重放所得库存与页面一致，无任意时刻负库存。
