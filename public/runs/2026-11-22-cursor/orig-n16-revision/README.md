# 小修订也得算数

打开 `change.html`。公告、流程、物资来自同一份数据。修订版默认 12 人、每人 3 张：签到 10:30–10:40，制作 10:40–11:30，收拾 11:30–11:40；共需 36 张，需补 26 张。原版仍是 8 人、10:00 开始、需补 14 张。活动名、日期、云尾室和 HOST-SYN-01 不变。

把人数改成 2 再重算，需纸 6、需补 0。切回原版后人数和时间回到最初，没有被这次输入改掉。`revised.json` 和 `change-log.json` 是默认修订的导出。

已知限制：开始后移和制作加长会把后面的环节顺延，不会只改标题。
